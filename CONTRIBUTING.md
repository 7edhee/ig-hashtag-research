# Contributing

Thanks for helping improve the Instagram Hashtag Research Tool.

## Guidelines

- Keep the program dependency-free unless a change clearly requires a package.
- Do not add Instagram scraping, credential collection, or access-control bypasses.
- Keep changes focused and explain behavior changes in the pull request.
- Test the program with Python 3.9 or newer before submitting.
- Do not commit generated CSV, HTML, cache, virtual-environment, or secret files.

## Local check

```bash
python3 hashtag_research.py "street photography"
```

## Pull requests

Describe what changed, why it is useful, and how you tested it. Small, focused pull requests are preferred.
